# ESTARA roadmap

1. Foundation: React/Vite frontend + FastAPI health and property endpoints.
2. Data model: persistent database, migrations, validation, authentication.
3. Search: real filters, pagination, map and saved searches.
4. ML recommendations: baseline content-based ranking with evaluation.
5. Price estimation: documented dataset, preprocessing, train/test evaluation, error metrics.
6. NLP: parse natural-language search into validated filters.
7. Computer vision/document assistance: only with suitable datasets, consent and safety checks.
8. Production: tests, security, observability, deployment and privacy review.

Demo property records are illustrative. They are not real verified listings.
